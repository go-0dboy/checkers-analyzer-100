# СтоКлетка — анализатор международных шашек (100 клеток)

Мобильное (mobile-first) веб-приложение + нативный Android-APK через Capacitor.

## Возможности

- Доска 10×10 с нумерацией полей 1–50 и координатами a–j / 1–10 (белые внизу, чёрные вверху, a1 — тёмное слева снизу).
- Строгие правила ФМЖД: обязательное взятие с правилом большинства, летающие дамки, простая бьёт назад, превращение в дамку только при остановке на последней горизонтали.
- Движок в отдельном потоке (Web Worker, протокол `go / info / done`): альфа-бета с итеративным углублением, quiescence-поиск взятий, дебютная книга, оценка/лучший ход/кандидаты/главная линия.
- База фигур: точные вердикты малофигурных окончаний (офлайн).
- Настройки: стрелка лучшего хода (вкл/выкл), авто-взятие с настраиваемым темпом, авто-ход, глубина анализа и время на ход движка.
- Форматы: FEN (Liens), PDN (загрузка/копирование/скачивание), автосохранение партии.
- 4 темы оформления, адаптивная отрисовка стрелок под размер экрана.

## Сборка APK (из git)

Требования: **Node ≥ 22**, **JDK 21** (Capacitor 7), Android SDK.

```
git push origin main      # debug-APK — артефакт прогона Actions
git tag v0.1.0 && git push --tags   # + подписанный release-APK в GitHub Release
```

Конвейер (`.github/workflows/build-apk.yml`): Node 22 → `npm ci` → typecheck →
`vite build` → `npx cap add/sync android` → **фирменные иконки** → JDK 21 → Gradle.

Локально: `bash scripts/build-apk.sh [--release]`.

Секреты для подписи: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` (без них собирается только debug).

## Иконки приложения

Источник — векторная `assets/app-icon.svg` (чёрная дамка с золотой короной на
тёмно-нефритовой подложке, в фирменных цветах приложения). В CI и локальном
скрипте ImageMagick растрирует её во все плотности (`mipmap-mdpi…xxxhdpi`,
круглые варианты) и в адаптивную иконку API 26+ (фон `#0B1416` + foreground).
Никаких стандартных зелёных роботов — только фирменный знак.

## Структура

```
src/engine/   core (правила) · search (α-β) · impl (воркер) · client · book · tablebase · pdn
src/state/    useGame (партия) · settings
assets/       app-icon.svg — фирменная иконка
```
