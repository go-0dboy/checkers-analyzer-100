# Scan 3.1 (WASM) — подключение

Положите сюда два файла:

```
public/scan/scan.js
public/scan/scan.wasm
```

и приложение автоматически переключится на Scan 3.1 (индикатор в шапке:
«Scan 3.1 · WASM»; в настройках пункт «Scan 3.1 (WASM)» покажет «модуль найден»).

## Откуда взять

Быстрее всего — готовая сборка **RoepStoep/scan-wasm** (Scan 3.1, адаптированный
для клиентского анализа lidraughts):

```
bash scripts/build-scan.sh
```

Скрипт сам клонирует scan-wasm, копирует артефакты (или компилирует
Draughts64/scan-3.1 через Emscripten с `MODULARIZE` + `ASYNCIFY`) и кладёт
результат сюда.

## Если модуль молчит

Мост (`src/engine/scan.ts`) общается по UCI-подобному протоколу
(`position fen …` / `go movetime …` → `info … pv …` / `bestmove 32-28`)
через stdin-пайп Emscripten. При любом сбое (нет файлов, другой протокол,
таймаут) анализ прозрачно уходит на встроенный движок — приложение
никогда не остаётся без анализа.
